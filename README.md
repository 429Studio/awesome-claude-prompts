## Contributing

To add a prompt, create a new `.md` file in the appropriate `prompts/<category>/` directory with the YAML frontmatter schema:

```yaml
---
title: "Your Prompt Title"
category: marketing  # one of: official-examples, prompt-engineering, technical, education, content-creation, marketing, business, creative, writing
tags:
  - tag1
  - tag2
source: null  # URL if adapted from elsewhere
author: null
model: null   # e.g. "Claude 3.5" if model-specific
has_image: false
added: "YYYY-MM-DD"
---
```
